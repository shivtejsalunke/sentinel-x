# Code of Conduct

## Standard

Keep project discussions respectful, constructive, and focused on the work. Critique implementation choices rather than people. Harassment, threats, discrimination, and publication of private information are not acceptable.

## Scope

This standard applies to repository issues, pull requests, code reviews, and project-related discussion spaces.

## Enforcement

Repository maintainers may edit or remove inappropriate contributions, close discussions, or restrict participation when needed. Report concerns privately to the repository owner.
