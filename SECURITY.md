# Security Policy

## Supported scope

Security reports are welcome for the assessment API, scenario handling, persistence, and repository build configuration. This project is a local-first prototype and is not approved for production or operational deployment.

## Reporting

Do not publish credentials, personal data, restricted material, or exploit details in a public issue. Use the repository owner's private GitHub contact or GitHub's private vulnerability reporting feature if it is enabled. Include affected commit, reproduction steps, impact, and a safe proof of concept where possible.

## Deployment boundary

The service is intended for local development. Production authentication, authorization, transport security, multi-user access controls, backup recovery, and a formal incident response process are not complete. Do not expose it to untrusted networks.
